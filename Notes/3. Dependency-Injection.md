# DI (Dependency Injection) in Spring Boot

- Dependency Injection means providing required objects (dependencies) to a class from outside instead of the class creating them itself.


#### Understanding "Dependency"

```
class Car {

    Engine engine = new Engine();

}

```
Here:

- Car depends on Engine
- So Engine is a dependency


#### With Dependency Injection

```
class Car {

    Engine engine;

    Car(Engine engine) {
        this.engine = engine;
    }
}

```
Now:

- Car does not create engine
- Someone else provides it

That is Dependency Injection.


### Types of Dependency Injection

#### 1. Field Injection
- Easy but less preferred.
```
    @Autowired
    Engine engine;

```

#### 2. Constructor Injection ✅ Recommended

```
@Component
class Car {

    private final Engine engine;

    public Car(Engine engine) {
        this.engine = engine;
    }
}
```

Advantages:

- Safer
- Easier testing
- Immutable dependencies


#### 3. Setter Injection

```
private Engine engine;

@Autowired
public void setEngine(Engine engine) {
    this.engine = engine;
}

```


## Important Spring Terms


| Term          | Meaning                  |
| ------------- | ------------------------ |
| Bean          | Object managed by Spring |
| IOC Container | Spring container         |
| Dependency    | Required object          |
| DI            | Injecting dependency     |
| `@Component`  | Creates bean             |
| `@Autowired`  | Inject dependency        |
