# Common Annotations


| Annotation        | Purpose                |
| ----------------- | ---------------------- |
| `@RestController` | REST API controller    |
| `@RequestMapping` | Base URL mapping       |
| `@GetMapping`     | GET request            |
| `@PostMapping`    | POST request           |
| `@PutMapping`     | PUT request            |
| `@DeleteMapping`  | DELETE request         |
| `@RequestBody`    | Read JSON request body |
| `@PathVariable`   | Read value from URL    |
| `@RequestParam`   | Read query parameter   |

### @RequestBody
- Sample URI  => POST: `http://localhost:8080/users/users`
- RequestBody param
```
{
  "name": "Saravanan",
  "age": 25
}
```




### @PathVariable
-   Sample URI => GET: `http://localhost:8080/users/users/101`

```
@GetMapping("/users/{id}")
public String getUser(@PathVariable int id) {
    return "User ID: " + id;
}

```
### @RequestParam 
- Sample URI  => GET: `http://localhost:8080/users?name=Saravanan`
```
 @GetMapping
public String search(@RequestParam String name) {
    return name;
}
```
