### Spring Boot 
```
Spring Boot  is a Java framework used to build:
```
- Web applications
- REST APIs
- Backend systems
- Enterprise applications
- It makes Java backend development much easier and faster.

### Why Spring Boot Was Created

```
Spring Boot helps developers build Java backend applications quickly with minimal configuration.
```

#### Before Spring Boot:

- Too much XML configuration
- Manual server setup
- Complex project setup

Spring Boot simplified everything.


## Main Features
### 1. Auto Configuration

Spring Boot automatically configures many things.

####  Example:
```
Database setup
Server setup
JSON conversion
```
### 2. Embedded Server

- Comes with built-in servers:
```
  Tomcat
  Jetty
```
- No need to install server manually.
- You just run the application.

### 3. Starter Dependencies

Easy dependency management.

Example:
```
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```
This single dependency adds:

- Spring MVC
- Tomcat
- JSON support

### 4. Production Ready

#### Includes:

- Logging
- Monitoring
- Health checks
