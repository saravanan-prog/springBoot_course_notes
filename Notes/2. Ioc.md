

### IoC (Inversion of Control) in Spring Boot

 - IoC is one of the most important concepts in Spring Framework and Spring Boot.

 - Spring Framework uses a concept called IoC (Inversion of Control) to manage objects automatically.

 ```
 IoC = Spring controls object creation instead of the programmer.
 ```


### Without IoC (Normal Java)

```
Normally in Java, you create objects manually.
```


### With IoC (Spring)

#### In Spring:
```


@Component
public class Engine {
    // Properties
}

And:

@Component
public class Car {

    @Autowired
    private Engine engine;
}

```

##### Now:

- Spring creates Engine
- Spring injects it into Car

You do NOT use:
```
new Engine()
```

### What Does Spring Manage?
#### Spring manages:

 -   Object creation
 -   Dependency injection
 -   Object lifecycle
```           
These managed objects are called:   Beans
```
