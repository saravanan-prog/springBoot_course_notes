# Spring Boot Architecture
    - It helps organize application code into separate layers.

### Main Architecture Flow
```
        Client
            ↓
        Controller Layer
            ↓
        Service Layer
            ↓
        Repository Layer
            ↓
        Database
```

### 1. Client can be:

- Browser
- Mobile app
- Postman
- Frontend application

### 2. Controller Layer

##### Handles:

- HTTP requests
- REST APIs
- Request mapping
