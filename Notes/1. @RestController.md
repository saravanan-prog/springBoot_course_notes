In Spring Boot / Spring MVC, these annotations and concepts are used to build REST APIs.

### @RestController

 - @RestController tells Spring that the class handles REST API requests
 -  and returns data directly (usually JSON).
 - It is equivalent to:
 ```
    @Controller
    @ResponseBody
```
```
@RestController
public class UserController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello";
    }
}
```
