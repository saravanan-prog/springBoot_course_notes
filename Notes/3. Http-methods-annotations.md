### HTTP methods 

#### GET

- Used to fetch data.
- Sample URI => GET `http://localhost:8080/users/1`

```
@GetMapping("/{id}")
public User getUser(@PathVariable int id) {
    return service.getUser(id);
}
```

Request Pram : /users?id=10
```
@GetMapping("/")
public String getUser(@RequestParam int id) {
    return "User ID: " + id;
}

```

#### POST



- Used to create data.
- Sample URI => POST `http://localhost:8080/users`
- Request Body 
```
    {
        "name": "Saravanan",
        "age": 25
    }
```
Example 

```
@PostMapping
public User createUser(@RequestBody User user) {
    return service.save(user);
}

```

#### PUT

- Used to update existing data.
- Sample URI => POST `http://localhost:8080/users`
- Request Body
```
    {
        "name": "Saravanan",
        "age": 25
    }
```

```
@PutMapping("/{id}")
public User updateUser(@PathVariable int id,
                       @RequestBody User user) {
    return service.update(id, user);
}
```

#### DELETE

- Used to remove data.
- Sample URI => DELETE `http://localhost:8080/users/1`

```
@DeleteMapping("/{id}")
public String deleteUser(@PathVariable int id) {
    service.delete(id);
    return "Deleted";
}

```
